Film Merkezi 0.12.0: native çekirdek ve ayrı imzalı site/çözümleyici paketleri.

Güncelleme Merkezi, GitHub depo keşfi, kullanıcı tarafından yayıncı güveni, bağımlılık denetimi, paket geri dönüşü ve kayıt aktarımı eklendi. 16 site için 32 paket ayrı eklenti deposundadır. Hiçbir depo önceden seçilmez.

Kontroller otomatik; indirme ve uygulama kullanıcı seçimiyledir. Klasik arayüz, logo, kayıtlar ve tek Media3 korunur. Yalnız site/çözümleyici güncellemeleri APK değiştirmeden yapılabilir; native özellikler APK güncellemesi gerektirir.

Eski deneme imzalı kurulumlarda önce 0.11.5 aktarım APK'sını kurup yedeği uygulama dışına kaydedin. Yedeği doğrulamadan eski uygulamayı kaldırmayın. Kalıcı imzaya ilk geçiş farklı sertifika nedeniyle normal üzerine kurulum değildir. Ayrıntılar: docs/android-signing-migration.md.

Emülatör doğrulamaları yapılmıştır; gerçek ARM TV kabulü henüz yapılmadı. Eklenti yayıncıları güvenilir olmalıdır; yardımcı süreç kötü niyetli kod için güvenlik sandbox'ı değildir.
