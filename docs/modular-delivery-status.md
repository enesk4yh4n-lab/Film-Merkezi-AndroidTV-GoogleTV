# Android modüler dağıtım çalışması

Onaylanan hedef: APK içinde native arayüz/kayıtlar/tek Media3; bağımsız imzalı Kotlin site ve çözümleyici paketleri. GitHub hesabı `enesk4yh4n-lab`; ana depo `Film-Merkezi-AndroidTV-GoogleTV`, eklenti deposu `Film-Merkezi-AndroidTV-GoogleTV-Eklentiler`.

Kararlar: public kaynak, kalıcı APK anahtarı; otomatik kontrol ve kullanıcı seçimiyle indirme/uygulama; kullanıcı tarafından eklenen depolar; bağımsız yayıncılar desteklenir. APK 0.11.5/35 eski deneme imzasıyla veri aktarımı, 0.12.0/36 kalıcı imzalı ilk kararlı teslim için ayrılmıştır. Henüz yayımlanmış yeni APK yoktur.
